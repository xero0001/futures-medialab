# 이환 캠페인 완료·청구·정산 시연

성과 보고 공개 → 관리자 캠페인 완료 → 청구·지급 초안 검토 → 수신 조직별 발행 → 외부 처리 결과 기록 순서로 연결합니다. 이 기능은 입금 확인·지급 결과를 기록하며 결제나 송금을 실행하지 않습니다.

## 완료 조건과 금액

- 현재 공식 제안의 모든 항목과 콘텐츠가 승인되어야 합니다.
- 각 항목의 최신 게시·성과 보고서가 공개되어야 합니다. 이전 공개본이 있어도 추가 보고가 검토·보완 중이면 완료할 수 없습니다.
- 활성 브랜드·수행 에이전시, 양수 확정 금액과 항목 총공급가를 확인합니다. 누락된 공급가나 기존 신청 기반 정산과의 충돌도 완료 전에 차단합니다.
- 검토 시점의 제안·제작·성과·경제 조건을 해시로 확인하며 변경된 내용을 다시 확인하지 않고 완료할 수 없습니다.
- 브랜드 청구액은 확정 제안의 `단가 × 수량` 합계입니다. 에이전시 지급액은 항목 총공급가(`supplierCost`)를 한 번씩 합산하며 수량을 다시 곱하지 않습니다.
- 통화 변환, 세금, 원천징수, 수수료를 추정하거나 자동 가산하지 않습니다. 금액은 decimal 문자열과 정수 최소 단위로 처리합니다.

## 각 역할의 화면

| 역할 | 화면 | 공개 범위 |
| --- | --- | --- |
| 브랜드 | `/advertiser/billing?lang=ko`, 캠페인 상세 청구 탭 | 자기 조직에 발행된 청구 항목·금액·기한·입금 확인 |
| 에이전시 | `/agency?section=payments&lang=ko`, 프로젝트 정산 탭 | 자기 조직에 발행된 지급 항목·금액·예정일·지급 확인 |
| 관리자 | 캠페인 검토의 완료·정산 패널 | 완료 근거, 브랜드 청구, 에이전시별 지급, 내부 메모·외부 처리 참조 |

초안은 수신 조직에 보이지 않습니다. 발행본의 금액·항목·안내는 고정됩니다. 외부 처리 기록에는 정확한 금액·통화·발행 후 처리 시각·참조가 필요합니다. 브랜드에는 공급가와 지급 내역이, 에이전시에는 브랜드 청구액과 다른 에이전시 금액이 포함되지 않습니다. 내부 메모와 외부 처리 참조도 관리자 전용입니다.

정산은 `DRAFT → ISSUED → PAID`이며 화면에서는 청구와 지급 문맥에 맞게 표시합니다. 캠페인 완료와 금전 처리 상태는 별개입니다. 실제 세금계산서 발급, 부분 입금·지급, 환불·취소·정정 발행, 은행·PG 연동은 이 범위에 포함되지 않습니다.

## 실제 DB 시연 데이터

기존 `brand@brand.com`, `agency@agency.com`, `admin@admin.com`을 사용합니다. 기존 이환 캠페인 16개와 보존된 QA 데이터는 유지합니다. 아래 4개는 별도 namespace `fm-demo-nte-settlement-v1`에 생성됩니다.

| 캠페인 ID 끝부분 | 시나리오 | 청구/지급 상태 |
| --- | --- | --- |
| `campaign-ready` | 도시 탐험 캠페인 완료 대기 | 성과 공개, 완료 버튼 사용 가능 |
| `campaign-draft` | 에이본 스토리 청구·정산 검토 | 캠페인 완료, 두 초안 비공개 |
| `campaign-issued` | 도시 하이라이트 청구·정산 발행 | 각각 발행, 처리 대기 |
| `campaign-paid` | 도시 탐험 입금·지급 확인 | 각각 처리 기록 완료 |

시연 게시 링크는 이환 공식 PV 참고 자료이고, 성과·가격·청구·지급은 모두 가상입니다. 명명된 테스트 계정의 비밀번호나 조직 권한은 변경하지 않습니다. 시드는 동일 namespace가 이미 존재하면 보존하고 다시 만들거나 상태를 초기화하지 않습니다.

```sh
node --experimental-strip-types apps/platform/scripts/seed-nte-settlement.mjs
node --experimental-strip-types apps/platform/scripts/seed-nte-settlement.mjs --apply
node --experimental-strip-types apps/platform/scripts/verify-nte-settlement.mjs
```

검증 결과는 `output/settlement-review/nte-seed-verification.json`에 저장합니다. 실제 HTTP 검증은 `settlement-smoke.mjs`에서 별도 QA 계정을 사용하며 QA 데이터는 삭제하지 않습니다.

## 실제 공개 채널을 참고한 후보 구성

사용자가 제공한 [퓨처스엔터테인먼트](https://futuresenter.com/)의 공개 크리에이터 목록과 각 YouTube 채널을 2026-11-02에 확인했습니다. 아래 역할은 공개 콘텐츠를 참고해 작성한 **이환 시연 기획 제안**이며 크리에이터가 제시하거나 수락한 조건이 아닙니다.

| 공개 채널 | 확인한 콘텐츠 성격 | 제안 역할 |

| [이다의게임방송](https://www.youtube.com/@%EC%9D%B4%EB%8B%A4%EC%9D%98%EA%B2%8C%EC%9E%84%EB%B0%A9%EC%86%A1) | 종합 게임 플레이·공략 | 직접 플레이와 초반 전투·성장 동선 |
| [박서림](https://www.youtube.com/@%EB%B0%95%EC%84%9C%EB%A6%BC) | 게임 스토리·세계관·지역 해설 | 에이본과 도시 탐험 입문 해설 |
| [프레이 TV](https://www.youtube.com/channel/UCSzHok6X5qXEO7cjvVnE62g) | LoL 중심 플레이·하이라이트, Shorts | 타 게임 이용자에게 소개하는 플레이 하이라이트 후보 |

구독자는 당시 YouTube 표시값의 근사치(14.4만, 8.29만, 69.8만)이며 실시간 연동값이 아닙니다. 검증되지 않은 평균 조회수는 제공하지 않습니다. 이환 협업·출연·단가·실제 소속 계약을 확정한 것으로 표시하지 않습니다.

`refresh-nte-creators.mjs --apply`는 기존 이환 시연 16개에 한정된 콘텐츠 보정 도구입니다. 제안 항목의 공개 이름·채널·플랫폼·참고 수치와 시연 설명만 보정하고 이전/이후 감사 기록을 남깁니다. ID, 승인·버전 상태, 금액·수량과 제작·성과 이력은 보존합니다. 내부 가상 크리에이터 슬롯은 테스트 조직의 기술적 연결로 유지합니다. 실제 운영 API의 발행본 불변 규칙을 완화하지 않습니다. 공식 제안 발행 전에는 실제 채널 정보도 브랜드에 공개하지 않습니다.
