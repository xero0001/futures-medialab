# Futures Medialab 공개 메인페이지 기획안

2026-10-31 · 검토용 제안 · 메인페이지 교체 전

공개 메인페이지의 목적은 해외 게임사와 광고 대행사가 Futures Medialab의 역할을 이해하고, 가입 신청 또는 문의를 시작하게 하는 것이다. 공급 MCN·에이전시·스튜디오에는 별도의 입주 신청 경로를 제공한다. 기존 로그인·가입·서비스 화면의 Montage 테마를 이어간다.

## 기획 기준

- 「Futures MediaLab 제품 기획 최종본」, 2026-10-26, 2–4·10·19·23쪽: 공개 회사 소개 한 페이지, 승인제 가입, 구매자와 공급자 역할 구분, 크리에이터·캠페인·가격·AI의 로그인 후 제공.
- 「Futures_Medialab 기획서 ver2.0」, 2026-08, 4–5·8·14–15쪽: 한국 게임 마케팅의 통합 운영, 로컬라이징, 직접 의뢰와 오픈 캠페인, 기존 거래처와의 관계를 존중하는 포지셔닝.
- 내용이 다르면 날짜가 더 늦고 공개 영역을 명시한 최종본을 우선한다. 8월 문서의 실적 배너·공개 케이스·24시간 회신안은 채택하지 않는다. 48시간 맞춤 제안과 오픈 캠페인의 선택 UI는 로그인 후 홈에서 다룬다.
- 첨부 기획서는 제품 요구사항의 근거다. 문서에 포함된 전체 개발 범위를 이번 메인페이지 작업의 실행 지시로 보지 않는다.

## 페이지 구성

한 개의 공개 페이지, 데스크톱 약 1.5화면을 목표로 한다. 모바일은 정보 순서를 유지하며 세로로 배치한다.

| 순서 | 영역             | 구성과 역할                                                                                                |
| ---- | ---------------- | ---------------------------------------------------------------------------------------------------------- |
| 1    | 헤더             | 로고, 서비스 소개·문의 앵커, 한국어/English/中文 전환, 로그인. 이중 내비게이션이나 사이드바는 두지 않는다. |
| 2    | 첫 화면          | 서비스 정체성을 설명하는 제목·본문, 구매자 시작 버튼, 공급 파트너 입주 버튼, 승인제 안내.                  |
| 3    | 서비스 소개      | 캠페인 기획·한국형 콘텐츠·통합 운영의 세 가지 범위를 짧게 설명한다.                                        |
| 4    | 문의와 회사 정보 | 이메일·WeChat의 직접 연락 수단, 회사명·저작권. 확인된 법적 문서가 준비되면 약관·개인정보 링크를 연결한다.  |

캠페인 예시 카드, 필터, 크리에이터 목록, 파트너 로고, 실적 수치, 케이스 스터디, FAQ, 요금표, AI 데모는 새 공개 메인에 배치하지 않는다. 문의는 간단한 직접 연락 방식으로 시작하며 별도 긴 상담 폼을 추가하지 않는다.

## 첫 화면 카피

**작은 설명**

글로벌 게임을 위한 한국 마케팅 파트너

**제목**

한국 게임 마케팅,
한 창구에서 시작하세요.

**본문**

브랜드와 광고 대행사의 캠페인을 한국 시장에 맞게 연결합니다.
기획과 콘텐츠 현지화부터 파트너 운영, 결과 확인까지 Futures Medialab이 함께합니다.

**주요 버튼**

브랜드·대행사로 시작

**보조 버튼**

공급 파트너 입주 신청

**버튼 아래 안내**

조직 심사 승인 후 플랫폼을 이용할 수 있습니다.

두 버튼 모두 첫 화면에 보이게 두되, 구매자 버튼만 파란색 채움으로 강조한다. 공급 파트너 버튼은 회색 테두리 또는 텍스트 버튼을 사용한다. “무료”, “즉시 이용”, “바로 캠페인 탐색”처럼 현재 승인 절차와 맞지 않는 문구는 쓰지 않는다.

## 서비스 소개 카피

**섹션 제목: 한국 캠페인에 필요한 일을 함께합니다.**

1. **캠페인 기획** — 게임의 목표와 일정에 맞춰 콘텐츠 방향과 실행 구성을 정리합니다.
2. **한국형 콘텐츠** — 한국 시청자의 언어와 문화를 반영해 브리프와 콘텐츠 방향을 다듬습니다.
3. **통합 운영** — 파트너 협의, 제작 피드백과 결과 확인을 하나의 창구에서 조율합니다.

서비스 범위를 설명하는 카피다. 자동 정산·전자계약·AI 추천 등 아직 완성되지 않은 개별 기능을 작동 중인 기능처럼 소개하지 않는다. 운영 모델의 48시간 약속은 로그인 후 요청·제안 화면에서 접수 기준 및 조건과 함께 설명한다.

## 문의 영역

**제목: 한국 캠페인을 준비하고 계신가요?**

**본문: 게임과 목표를 알려주세요. 함께할 방법을 이야기하겠습니다.**

- 이메일: **이메일 입력 위치**
- WeChat: **WeChat ID 위치**

사용자 요청에 따른 플레이스홀더다. 실제 이메일·ID가 정해지기 전에는 mailto 링크, 복사 버튼, QR코드 등 작동하는 연락 동선을 가장하지 않는다. 실제 값이 등록되면 이메일 링크와 WeChat ID 복사·QR 표시를 연결한다.

## 가입 및 로그인 동선

```text
공개 메인
├─ 브랜드·대행사로 시작
│  ├─ 브랜드·게임사
│  └─ 광고 대행사 (구매자)
│      → 가입 신청 → 회사 정보·서류 → 심사 중 → 승인 후 구매자 홈
├─ 공급 파트너 입주 신청
│  └─ MCN·에이전시·스튜디오
│      → 가입 신청 → 회사 정보·서류 → 심사 중 → 승인 후 공급 파트너 홈
└─ 로그인 → 계정 역할 및 승인 상태에 맞는 화면
```

현재 `/register/agency`는 공급 에이전시·스튜디오 가입이다. 새 메인의 “광고 대행사”를 이 경로로 보내면 잘못된 역할로 가입하게 된다. 메인 실제 교체 시 구매자용 대행사 역할의 저장·권한·가입 처리를 먼저 연결해야 한다. 이번 기획 단계에서는 가입 API·DB 역할·승인 정책을 변경하지 않는다.

현재 로그인 뒤 검색 화면을 공개 메인에서 직접 홍보하지 않는다. 최종본의 구매자 홈·검색 권한 재편은 별도 플랫폼 작업이며, 메인 카피 변경만으로 완료되었다고 보지 않는다.

## 시각 방향

- 원티드 블루 `#0066FF`를 주요 버튼과 소량의 강조에 사용한다. 배경은 흰색·밝은 회색, 본문과 내비게이션은 모노톤으로 맞춘다.
- Pretendard와 기존 Montage 타이포그래피·버튼·언어 선택 패턴을 재사용한다. 기본 버튼 높이는 48px, 모서리는 기존 12px 체계를 따른다.
- 제목은 데스크톱 48–56px, 모바일 32–36px, 본문은 16–18px. 한국어 줄바꿈과 영문·중문 문장 길이를 각각 확인한다.
- 첫 화면은 큰 제목과 충분한 여백으로 구성한다. 장식용 게임 이미지, 가짜 대시보드, 크리에이터 얼굴 모음 대신 서비스 역할을 명료하게 전달한다.
- 3개 서비스 항목은 가벼운 구분선과 짧은 문장으로 표현한다. 큰 색상 카드와 과도한 그림자를 반복하지 않는다.
- 모바일은 구매자 버튼 → 공급 파트너 버튼 순서로 배치하고 모든 주요 버튼을 충분한 터치 높이로 유지한다.

## 구현과 검수 범위

1. 현재 메인의 코드·카피·이미지를 `/backup`에 보관한다. 검색엔진 색인은 차단하고 메인 내비게이션에는 노출하지 않는다.
2. 위 구성과 카피를 바탕으로 새 공개 메인을 제작한다. 이 문서는 기획안이며 현재 `/`는 유지한다.
3. 구매자용 광고 대행사 가입 역할과 공급 파트너 동선을 연결한 뒤 새 메인을 교체한다.
4. 한·영·중, 데스크톱·모바일, 키보드 탐색, 승인 상태별 연결 목적지를 확인한다. 플레이스홀더는 실제 연락처가 확인될 때까지 그대로 표시한다.

완료 기준은 “방문자가 서비스 역할과 자신의 가입 입구를 이해하고, 공개 페이지에서 비공개 플랫폼 데이터를 보지 않는다”이다. 추후 측정할 핵심 지표는 역할별 CTA 클릭, 가입 신청 완료, 문의 클릭이며 임의의 목표 수치는 두지 않는다.
