# 이환 제작·검수 내부 시연

기존 `brand@brand.com`, `agency@agency.com`, `admin@admin.com`의 계정·비밀번호·조직 권한을 유지한다. 기존 공식 제안 시연 4개를 보존하고, 승인된 제안부터 제작·검수로 이어지는 캠페인 6개를 실제 DB에 추가한다. 크리에이터·구성안·가격·검수 이력은 가상 자료다.

## 화면과 흐름

1. 브랜드가 공식 제안의 모든 항목을 승인하면 제작 항목이 생긴다. 기존 승인본은 관리자의 `제작 항목 준비`로 연결한다.
2. 에이전시는 자신의 프로젝트에서 배정된 항목에 제목·HTTPS 콘텐츠 링크·설명을 제출한다.
3. 관리자는 캠페인 상세 `제작·검수`에서 원문을 확인한다. 에이전시에 보완을 요청하거나 브랜드 공개용 제목·링크·설명을 별도로 작성하고 미리보기를 확인해 공개한다.
4. 브랜드는 캠페인 상세 `제작·검수`에서 공개된 버전을 승인하거나 수정 사유를 남긴다.
5. 에이전시의 수정본은 새로운 버전이다. 관리자가 다시 공개하기 전에는 브랜드에 원문이나 링크가 나타나지 않는다.

브랜드·에이전시의 MEMBER 역할은 조회만 가능하다. 승인·제출은 OWNER/ADMIN, 공개·배정은 활성 플랫폼 관리자만 처리한다. 수정·승인 이력은 정확한 버전에 연결한다. 승인된 콘텐츠를 자동 게시하거나 비용을 지급하지 않는다.

## 저장된 시연 장면

| 캠페인 | 제작 상태 | 시연할 행동 |
| --- | --- | --- |
| 이환 · 헤테로 시티 첫 산책 | 제출 대기 | 에이전시가 첫 구성안을 제출 |
| 이환 · 이상 현상 탐험 노트 | 관리자 검수 중 | 관리자가 비공개 원문을 확인하고 브랜드용으로 공개 |
| 이환 · 도시의 색을 담는 45초 | 에이전시 보완 | 운영팀 피드백을 보고 수정본 제출 |
| 이환 · 에이본의 하루 | 브랜드 검수 대기 | 브랜드가 공개본을 승인 또는 수정 요청 |
| 이환 · 도시 속 반전 찾기 | 브랜드 수정 요청 | 브랜드 피드백을 반영해 수정본 제출·재공개 |
| 이환 · 초보 감정사 체크리스트 | 승인 완료 | v1 수정 요청 → v2 제출·관리자 공개 → 브랜드 승인 이력 확인 |

기존 `[시연] 이환 · 초보 감정사 가이드`의 승인 항목 3개도 제출 대기 제작 항목으로 연결한다. 기존 제안 상태·승인 이력은 덮어쓰지 않는다.

## 이미지와 제출 자료

공식 사이트의 도시 키 이미지와 게임 아이콘을 캠페인 목록·상세·제작 카드에 사용한다. 아이콘은 게임 식별용이며 크리에이터 사진으로 사용하지 않는다. [공식 사이트](https://nte.perfectworld.com/kr/)와 [원본 파일 출처](../../apps/platform/public/demo/nte/SOURCES.md)를 기록했다. 이미지의 권리는 Hotta Studio / Perfect World에 있다.

시연 제출 링크는 공식 참고 이미지이고, 설명에는 실제 DB에 저장한 콘텐츠 구성안을 담는다. 가상의 크리에이터가 제작한 실제 영상으로 표시하지 않는다. 외부 URL을 서버에서 가져오거나 자동 실행하지 않는다.

## 재실행과 데이터 범위

`apps/platform/scripts/seed-nte-production.mjs`는 기본적으로 읽기만 한다. `--apply`는 `fm-demo-nte-production-v1-*` 네임스페이스와 `requirements.productionSeed=nte-production-v1`을 검사하고 6개 캠페인을 생성한다. 기존 시연 세트가 있으면 진행 상태를 초기화하지 않는다. 원래의 이환 시연 캠페인에 게임 이미지 메타데이터를 추가하고 이미 승인된 항목의 제작 연결만 준비한다.

추가 마이그레이션 `20261102010000_add_production_review`는 제작 항목·버전·요청 재시도 기록 테이블을 만든다. 기존 신청 단위 콘텐츠 API를 통한 우회를 막기 위해 공식 제안을 사용하는 캠페인의 레거시 제출·승인 쓰기는 차단한다. 조회할 때 브랜드에는 공개 필드만 명시적으로 선택한다.
